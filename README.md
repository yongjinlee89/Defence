# 🏰 디펜스 — 영토 확장 실시간 디펜스

여러 명이 같은 지도에서 실시간으로 공장을 지어 돈을 벌고, 타워·병력으로 지키고, 이웃(중립·다른 플레이어)을 쳐서 영토를 넓히는 브라우저 게임입니다.
[컴퍼니](https://github.com/yongjinlee89/company)와 같은 스택(Node + Express + Socket.IO, 바닐라 JS 클라이언트, Render 무료 배포)을 쓰며, 트래픽 절감 구조도 그대로 가져왔습니다.

## 게임 규칙 (1분 요약)

- **실시간**: 턴이 없습니다. 서버가 0.25초마다 시뮬레이션하고, 화면은 1초마다(행동은 즉시) 갱신됩니다. 제한 시간 10/15/20분.
- **영토**: N×N 격자(2인 4×4, 3~4인 5×5, 5~6인 6×6). 각 땅에 등급(💰 1~3개)과 부지 칸(4~6)이 있습니다. 상하좌우 인접 땅으로만 이동·공격합니다.
- **돈**: 부지에 지은 🏭 공장이 초당 `2 × 땅 등급 × 레벨`을 법니다. 타워는 돈을 벌지 않습니다. 부지는 공장과 타워가 같이 쓰므로 어디에 뭘 지을지 골라야 합니다.
- **병력 3종**: 🛡️ 전차는 🪖 보병을, 보병은 ✈️ 항공기를, 항공기는 전차를 잡습니다. 병력은 초당 가격의 0.5%를 유지비로 씁니다. 돈이 바닥나면 흩어집니다.
- **타워 3종**: 🔫 기관총은 보병, 🏯 포탑은 전차, 🚀 대공포는 항공기를 막습니다. 체력이 있고 부서지며, 전투 중이 아니면 천천히 수리됩니다.
- **공격**: 내 땅을 누르고 "공격"(전부/절반) → 인접한 남의 땅을 누릅니다. 전투는 땅 단위 소모전이며, 땅을 누르면 전투 장면을 볼 수 있습니다. 이기면 그 땅과 공장을 뺏고 생존 병력이 주둔합니다. 전투 중 증원·후퇴가 가능합니다.
- **습격**: 75초마다 약탈대가 각 플레이어의 땅 하나를 칩니다(12초 전 예고). 못 막으면 그 땅은 중립이 됩니다. 라운드가 오를수록, 땅이 많을수록 커집니다.
- **승리**: 제한 시간 종료 시 순자산(돈+건물+병력+땅) 순위. 땅을 전부 잃으면 탈락, 한 명만 남으면 즉시 종료.

수치는 게임 안 "도움말" 탭과 `src/game.js` 맨 위 상수에 있습니다.

## 실행

```bash
npm install
npm start          # http://localhost:7863
npm test           # 규칙·방·봇 테스트
npm run balance    # 봇 4명 자동 대전 + 라운드별 방어 검증
```

대기실에서 🤖 컴퓨터를 추가하면 혼자서도 해 볼 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/game.js` | 규칙 엔진. 맵·경제·전투·습격·점수. 순수 로직만 (네트워크 없음) |
| `src/bot.js` | 컴퓨터 플레이어. `Game`의 공개 메서드만 호출 |
| `src/room.js` | 방(대기실/게임 루프/봇 틱), 브로드캐스트용 완전한 상태 생성 |
| `src/diff.js` | 상태 diff/패치 프로토콜 (클라이언트에 사본) |
| `server.js` | Express + Socket.IO. diff 패치 브로드캐스트, 백그라운드 절전, `/healthz` |
| `public/` | 클라이언트 (캔버스 지도, 전투 장면 애니메이션, 영토/순위/도움말/기록 탭) |

## 트래픽 절감 (Render 무료 5GB/월 대응)

- 서버는 상태 전체가 아니라 **직전 스냅샷과의 diff 패치**만 보냅니다. 버전이 어긋나면 클라이언트가 `resync`로 전체를 다시 받습니다.
- 웹소켓 전용(폴링 폴백 제거), perMessageDeflate, 정적 파일 gzip.
- `publicState()`는 화면에 쓰는 값만 화면 해상도로 반올림해 담습니다(병력 0.1 단위, 돈 정수, 타워 체력은 손상됐을 때만).
- 전투 장면 애니메이션은 브라우저가 "현재 병력 수"만 보고 지어서 그립니다. 유닛 위치는 서버가 보내지 않습니다.
- 기록/채팅은 배열이 아니라 id 키 객체로 보내 창 밀림 재전송을 막습니다.
- 탭을 20초 이상 덮어 두면 방송 채널에서 빠지고, 30분 뒤 연결을 끊습니다.
- 실측: 전체 상태 약 2.5KB, 게임 중 접속당 평균 수백 B/s (JSON 기준, 압축 전).

## 배포 (GitHub + Render)

1. GitHub에 저장소를 만들고 이 폴더를 push 합니다.
2. [Render Blueprints](https://dashboard.render.com/blueprints)에서 **New Blueprint Instance** → 저장소를 연결하면 `render.yaml`을 읽어 무료 플랜으로 배포됩니다.
3. 배포된 `https://….onrender.com` 주소를 공유하세요. 같은 방 코드를 입력하면 같은 게임에 들어옵니다.
