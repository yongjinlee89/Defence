# 🏰 디펜스 — 영토 확장 실시간 디펜스

여러 명이 같은 지도에서 실시간으로 땅을 개발해 돈을 벌고, 타워·병력으로 지키고, 이웃(중립·다른 플레이어)을 쳐서 영토를 넓히는 브라우저 게임입니다.
[컴퍼니](https://github.com/yongjinlee89/company)와 같은 스택(Node + Express + Socket.IO, 바닐라 JS 클라이언트, Render 무료 배포)을 쓰며, 트래픽 절감 구조도 그대로 가져왔습니다.

## 게임 규칙

- **실시간**: 턴이 없습니다. 서버가 0.25초마다 시뮬레이션하고, 화면은 1초마다(행동은 즉시) 갱신됩니다. 제한 시간 10/15/20분.
- **영토**: N×N 격자(2인 4×4, 3~4인 5×5, 5~6인 6×6). 각 영토에는 자원(철/석유/식량/없음), 부지 수, 건물, 주둔 병력이 있습니다. 상하좌우 인접 영토로만 이동·공격할 수 있습니다.
- **돈 버는 법**: 타워는 돈을 벌지 않습니다. 부지에 광산·유정·농장(자원 채취), 공장(철+석유→부품), 상점(초당 현금)을 지어야 합니다. 부지는 타워와 함께 쓰므로 **경제 vs 방어**를 영토마다 저울질해야 합니다. 경제 건물은 3레벨까지 증설할 수 있습니다.
- **시장**: 철·석유·식량·부품을 돈으로 사고팝니다. 사면 오르고 팔면 내리며(수요·공급), 시간이 지나면 기준가로 돌아옵니다. 수수료 2%. 자원별 "자동 판매"를 켜면 일정량만 남기고 계속 팝니다.
- **병력**: 보병(싸고 많음), 전차(직사, 타워 파괴), 포병(곡사, 타워에 강하지만 보병에 약함), 항공기(전차·포병에 강함, 대공포·보병만 맞출 수 있음). 돈+자원으로 뽑아 영토에 주둔시키고, 인접한 내 땅으로 즉시 옮깁니다.
- **타워**: 기관총탑(보병), 포탑(전차), 박격포(곡사, 보병·포병), 대공포(항공기). 전투에 참가하고 체력이 있으며 부서집니다. 전투 중이 아니면 천천히 수리됩니다.
- **전투**: 인접한 남의 땅에 병력을 보내면 영토 단위 소모전이 시작됩니다. 양쪽이 매 틱 상성표에 따라 서로를 갉아먹습니다. 공격자가 이기면 땅과 경제 건물을 빼앗고 생존 병력이 주둔합니다. 전투 중에도 양쪽 다 증원할 수 있고, 공격자는 후퇴할 수 있습니다.
- **습격(라운드)**: 75초마다 NPC 약탈대가 각 플레이어의 영토 하나를 칩니다(12초 전에 예고). 막지 못하면 그 땅은 중립이 됩니다. 라운드가 오를수록 전차·포병·항공기가 섞여 옵니다.
- **승리**: 제한 시간 종료 시 순자산(돈+자원+건물+병력+땅) 순위. 땅을 전부 잃으면 탈락, 한 명만 남으면 즉시 종료.

상성표와 유닛·건물 수치는 게임 안 "상성" 탭에 있습니다. 규칙 상수는 `src/game.js` 맨 위에 모여 있습니다.

## 실행

```bash
npm install
npm start          # http://localhost:7863
npm test           # 규칙·방·봇 테스트
```

대기실에서 🤖 컴퓨터를 추가하면 혼자서도 해 볼 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/game.js` | 규칙 엔진. 맵·경제·시장·전투·습격·점수. 순수 로직만 (네트워크 없음) |
| `src/bot.js` | 컴퓨터 플레이어. `Game`의 공개 메서드만 호출 |
| `src/room.js` | 방(대기실/게임 루프/봇 틱), 브로드캐스트용 완전한 상태 생성 |
| `src/diff.js` | 상태 diff/패치 프로토콜 (클라이언트에 사본) |
| `server.js` | Express + Socket.IO. diff 패치 브로드캐스트, 백그라운드 절전, `/healthz` |
| `public/` | 클라이언트 (캔버스 지도 + 영토/시장/순위/상성/기록 탭) |

## 트래픽 절감 (Render 무료 5GB/월 대응)

컴퍼니와 동일한 방식입니다.

- 서버는 상태 전체가 아니라 **직전 스냅샷과의 diff 패치**만 보냅니다. 버전이 어긋나면 클라이언트가 `resync`로 전체를 다시 받습니다.
- 웹소켓 전용(폴링 폴백 제거), perMessageDeflate, 정적 파일 gzip.
- `publicState()`는 화면에 쓰는 값만 화면 해상도로 반올림해 담습니다(병력 0.1 단위, 돈 정수, 타워 체력은 손상됐을 때만).
- 기록/채팅은 배열이 아니라 id 키 객체로 보내 창 밀림 재전송을 막습니다.
- 탭을 20초 이상 덮어 두면 방송 채널에서 빠지고, 30분 뒤 연결을 끊습니다.
- 실측: 전체 상태 약 4.3KB, 게임 중 접속당 평균 수백 B/s (JSON 기준, 압축 전).

## 배포 (GitHub + Render)

1. GitHub에 저장소를 만들고 이 폴더를 push 합니다.
2. [Render Blueprints](https://dashboard.render.com/blueprints)에서 **New Blueprint Instance** → 저장소를 연결하면 `render.yaml`을 읽어 무료 플랜으로 배포됩니다.
3. 배포된 `https://….onrender.com` 주소를 공유하세요. 같은 방 코드를 입력하면 같은 게임에 들어옵니다.
